## 자판기
* 자판기에는 5개의 음료가 있다.
* 사용자가 금액을 투입하면 원하는 음료를 선택할 수 있다.
* 음료 구매 후 잔돈을 반환한다.
* 재고가 0이 되면 해당 음료는 구매를 할 수 없다.
* 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, 에러 메시지 출력 후 그 부분부터 입력을 다시 받는다.

### 입력
* 투입 금액
```
자판기에 투입할 금액을 입력해 주세요.
5000
```
* 음료 선택
```
구매할 음료의 번호를 입력해 주세요.
1. 콜라 - 1000원 (재고: 5개)
2. 사이다 - 1200원 (재고: 3개)
3. 물 - 500원 (재고: 10개)
1
```

### 출력
* 자판기 상태
```
=== 자판기 ===

[음료 목록]
1. 콜라 - 1000원 (재고: 5개)
2. 사이다 - 1200원 (재고: 3개)
3. 물 - 500원 (재고: 10개)
```
* 투입한 금액 현황
```
5000원을 투입했습니다.
```
* 최종 결과
```
=== 구매 내역 ===
콜라
반환 금액: 4000원
```
